Demo Version Tech Stack

Functional browser demonstration

This section describes the technologies used by the accessible portfolio demo.

Demo Frontend

HTML5, responsive CSS3, Vanilla JavaScript, mobile-first navigation, accessible tabs, and validated forms.

Demo Storage

LocalStorage with browser-based equipment records. No server or cloud database is represented.

Demo Validation

Required asset code, equipment name, location, duplicate-code prevention, and client-side search filtering.

Demo Hosting

Static Vercel deployment over HTTPS.

Demo Features

QR lookup simulation, equipment registration, local records, asset search, keyboard-operable tabs, and live status messages.

Demo Limitations

No native camera, QR decoding, production authentication, remote API, server database, cross-device synchronization, or export service connects to the demo.

    Complete System Tech Stack

    Complete mobile inventory architecture

    This section describes the complete technical architecture of the full inventory system.

    The accessible portfolio version is optimized for demonstration and can run without a connected production server. The Complete System Tech Stack section documents the full technical architecture used for the complete business system version.

    Complete System Frontend

    Flutter and Dart, responsive mobile interfaces, Material components, form validation, state management, mobile navigation, dashboard summaries, Android compatibility, and accessible labels.

    Complete System Backend

    PHP and Laravel REST services with controllers, models, service layer, server-side validation, asset registration, inventory movement logic, synchronization services, report generation, and background jobs.

    Complete System Database

    MySQL server database and SQLite offline storage; entities for users, roles, locations, asset categories, equipment, QR codes, inventory movements, assignments, maintenance, sync records, and audit logs; keys, indexes, transactions, migrations, seeders, and backups.

    Complete System Authentication

    Laravel Sanctum tokens, password hashing and reset, secure token storage, email verification, Administrator and Inventory Staff roles, permission policies, login protection, and secure logout.

    Complete System APIs & Integrations

    REST API, JSON validation, asset and inventory endpoints, camera integration, QR scanning, offline synchronization, PDF and Excel export, email notifications, and device connectivity checks.

    Complete System Security

    Token authorization, input validation and sanitization, Eloquent ORM, rate limiting, HTTPS, environment variables, secure local token handling, authorization policies, audit logs, encrypted transport, and backup recovery.

    Complete System Testing

    Flutter unit and widget testing, Laravel feature and API testing, database and synchronization testing, camera and QR testing, offline workflow testing, role-permission testing, responsive testing, accessibility testing, and Android device testing.

    Complete System Deployment

    Signed Android application package, Laravel-compatible Apache or Nginx server, PHP runtime, MySQL server, SSL, domain, environment configuration, database migrations, queue worker, file storage, error logging, automated backup, and CI/CD when applicable.

    The public portfolio demo runs independently for easy access. Backend and database services are represented under the Complete System Architecture and are not connected to the public demonstration deployment.
