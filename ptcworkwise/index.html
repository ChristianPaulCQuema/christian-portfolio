Role-based Modules

Separate tools for each user group

Controls user accounts, approvals, employee records, departments, documents, reports, schedules, task calendars, announcements, and messaging.

Dean / Assistant Dean Module

Supports department oversight, professor management, document and report handling, curriculum tools, availability, schedules, tasks, chat, and profile settings.

Employee Module

Gives employees access to announcements, department details, document requests, report uploads, schedules, availability, tasks, chat, and profile management.

Complete System Tech Stack

PTC WorkWise complete system architecture

The accessible portfolio version is optimized for demonstration and can run without a connected production server. The Complete System Tech Stack section documents the full technical architecture used for the complete business system version.

Demo Version

Frontend: HTML5, CSS3, and JavaScript gallery components. Storage: static screen metadata only. Validation: client-side gallery controls. Hosting: static Vercel pages. Limitation: no HR records or authentication services connect to the public gallery.

Complete System Frontend

HTML5, CSS3, JavaScript, Bootstrap, responsive role dashboards, accessible forms, client-side validation, calendar components, document screens, and mobile-compatible layouts.

Complete System Backend

PHP, modular MVC-style controllers and services, server-side validation, employee-record logic, document and report processing, scheduling, task management, notifications, and PDF report generation.

Complete System Database

MySQL relational design with users, roles, permissions, employees, departments, documents, reports, schedules, tasks, announcements, messages, and audit records; foreign keys, indexes, transactions, migrations, backups, and recovery procedures.

Complete System Authentication

PHP secure sessions, password hashing, password reset, HR, Dean, Assistant Dean, and Employee roles, permission-based authorization, login protection, and secure logout.

Complete System APIs & Integrations

JSON REST endpoints for records, documents, reports, schedules, tasks, and notifications; email alerts, PDF documents, Excel reports, and calendar data exchange.

Complete System Security

CSRF tokens, output escaping, prepared queries, input validation and sanitization, permission checks, rate limiting, HTTPS, secure cookies, environment variables, audit logs, and database backup.

Complete System Testing

Functional, unit, integration, database, permission, document-workflow, schedule-conflict, responsive, accessibility, end-to-end, and browser compatibility testing.

Complete System Deployment

Apache or Nginx, PHP runtime, MySQL server, SSL, domain and environment configuration, database migrations, file storage, error logging, automated backup, and CI/CD when applicable.

Connection disclosure: The public portfolio demo runs independently for easy access. Backend and database services are represented under the Complete System Architecture and are not connected to the public demonstration deployment.
